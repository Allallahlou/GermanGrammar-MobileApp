# Deutsch Grammatik - موقع تعلم القواعد الألمانية

## 🚀 طريقة التشغيل

### الطريقة 1: باستخدام Python + Flask

1. تأكد من تثبيت Python
2. نصب Flask:
   ```bash
   pip install flask
   ```
3. شغل التطبيق:
   ```bash
   python app.py
   ```
4. افتح المتصفح على: `http://127.0.0.1:5000`

### الطريقة 2: مباشرة بدون Python

1. افتح ملف `index.html` في أي متصفح حديث
2. الموقع يعمل كـ Single Page Application (SPA)

## 📁 هيكل الملفات

```
├── app.py              # خادم Flask (اختياري)
├── index.html          # الصفحة الرئيسية
├── data.json           # بيانات التمارين (255 سؤال)
└── static/
    ├── style.css       # التنسيقات
    ├── script.js       # المنطق والتفاعل
    └── data.json       # نسخة للخادم
```
